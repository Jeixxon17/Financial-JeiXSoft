# Notice

Aviso del asesor (adición: la app avisa al registrar gastos y en el inicio).

- El consumidor da el título, el texto y el tono: `is-danger` (no queda dinero libre), `is-warning` (casi al límite), `is-success` (vas bien) o neutro.
- El tono siempre se dice también en el título, no solo con el color.
