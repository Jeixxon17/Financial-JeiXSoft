# QuickAction

Acción rápida: círculo de 52px con icono y la etiqueta debajo. Se usan en fila de cuatro (`jx-actions`) bajo la tarjeta principal.

- El consumidor da icono, etiqueta corta (una o dos palabras: "Gasto", "Ingreso", "Transferir", "Más") y la acción.
- `is-active` pinta el círculo en `primary`: úsalo solo en la acción más usada.
