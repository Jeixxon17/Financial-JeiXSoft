# BalanceHeader

Encabezado de la pantalla de inicio: avatar, etiqueta "Saldo disponible", el saldo en `amount-lg` y un botón circular a la derecha.

- El consumidor da las iniciales o foto, el saldo ya formateado (pesos, sin decimales) y la acción del botón.
- El saldo usa cifras tabulares; si es negativo va con signo − y en `danger`.
