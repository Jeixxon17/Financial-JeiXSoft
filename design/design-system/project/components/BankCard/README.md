# BankCard

La tarjeta bancaria con el resplandor azul: muestra una cuenta o tarjeta de crédito como protagonista.

- El consumidor da el nombre del banco (en cursiva, como marca), los últimos 4 dígitos o el número en grupos de 4, el titular y la fecha o el dato clave (pago mínimo, cupo).
- Fondo `card-base` con `accent-glow`; el texto va en `card-ink` y las etiquetas en `card-ink-muted` en ambos temas (la tarjeta siempre es oscura).
- No dibujes logos de franquicias (Visa, Mastercard): escribe el nombre del banco o de la cuenta.
