# BottomNav

Navegación inferior flotante en píldora: cinco destinos con iconos; el activo es un círculo `ink` con el icono en `on-inverse`.

- El consumidor da los destinos (Inicio, Movimientos, Cuentas, Presupuesto, Perfil) y cuál está activo; cada botón lleva `aria-label`.
- Flota a `space-5` del borde inferior más el área segura del celular.
